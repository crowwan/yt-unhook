# 릴리스 전 수동 QA

릴리스 이슈를 만들 때 이 목록을 복사해 실제 Release 빌드로 확인한다.
스펙의 `(수동 QA)` 수용 기준과, 자동화하기 어려운 버그 재발 방지 항목을 여기에 모은다.

## 공통

- [ ] 새로 설치(또는 저장 데이터 초기화) 후 첫 실행이 정상이다
- [ ] 이전 버전 데이터가 그대로 남아 있다 (업데이트 설치)
- [ ] 이번 마일스톤 스펙의 기본 흐름을 처음부터 끝까지 한 번씩 해 봤다

## 스택 공통

<!-- web 스택 기본 항목을 유저스크립트(아이폰 Safari + Userscripts 앱) 환경에 맞게 바꿨다 -->

- [ ] 빌드한 `dist/*.user.js` 를 아이폰 Userscripts 앱에 설치(또는 갱신)하고 m.youtube.com 에서 기본 흐름이 동작한다

- [ ] Safari 를 완전히 닫았다 다시 열어도 설정이 유지된다
- [ ] Mac Safari 원격 웹 속성(Web Inspector) 콘솔에 스크립트 에러가 없다
- [ ] 페이지 안에서 이동(홈 → 영상 → 검색 → 뒤로가기)해도 숨김이 계속 적용된다
